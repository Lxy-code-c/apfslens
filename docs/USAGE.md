# 使用说明

ApfsLens 是一个**只读**的 APFS 浏览工具：插上 Mac 格式化过的盘（或打开 .dmg / .img 镜像），双击就能进去看卷、进目录、导出文件。三个平台都是图形程序，没有命令行入口。

---

## 1. 装哪个包

| 系统 | 下载 | 打开方式 |
|---|---|---|
| Windows | `ApfsLens-<版本>-windows.zip` | 解压（平铺，不套文件夹）→ 双击 `apfslens-x64.exe`；或双击 `launch.cmd`（按 CPU 自动选 x64/x86/ARM64 并申请管理员权限） |
| macOS Apple Silicon | `ApfsLens-<版本>-mac-arm64.zip` | 解压得到 `ApfsLens.app` → 拖进「应用程序」→ 双击 |
| macOS Intel | `ApfsLens-<版本>-mac-x64.zip` | 同上 |
| Linux x64 | `ApfsLens-<版本>-linux-amd64.tar.gz` | 解压 → 双击 `apfslens-linux-x64`，或把 `apfslens.desktop` 拖进桌面 |
| Linux ARM64 | `ApfsLens-<版本>-linux-arm64.tar.gz` | 同上 |

macOS 未做公证，首次打开若提示“无法验证开发者” → 右键 → 打开。
Linux 个别解压工具会丢可执行权限，必要时 `chmod +x apfslens-linux-x64`。

## 2. 界面怎么用

三步：**选盘 → 选卷 → 浏览**。

1. 左侧列出本机磁盘与分区，能识别 GPT / MBR / Apple 分区表，标出哪块带 APFS；
2. 选中后看到 APFS 容器里的卷（名称、角色、是否密封、是否加密、是否可用）；
3. 选卷进目录：面包屑回上级，搜索框在卷内按文件名搜，右上角可切换快照时间点；
4. 选中文件点「导出」→ 落到系统「下载」目录（重名自动加序号，不覆盖）。

Windows 版另有：格式化（NTFS / exFAT / FAT32，按分区或整盘）、APFS 模板还原、盘符映射「挂载到此电脑」（只读）、FileVault 解锁、一键诊断。

## 3. 权限

- **读整块物理盘需要管理员权限**：Windows 程序会自己申请；Linux 用 `sudo` 启动一次或把用户加进 `disk` 组；macOS 首次会弹「完全磁盘访问」，按提示允许。
- **读镜像文件不需要任何权限**（`.dmg` / `.img`）。
- 程序只监听 `127.0.0.1` 的随机端口，不联网、不上传任何数据。

## 4. 隐藏项

`.` 开头的项（`.DS_Store`、`._xxx`、`.Spotlight-V100`）在**列目录、搜索、导出**三处全部屏蔽：列表里看不到，搜不到，直接请求下载返回 403。

## 5. 能力边界

| 能力 | Windows | Linux | macOS |
|---|---|---|---|
| 浏览卷 / 目录 / 文件 / 快照 | ✅ | ✅ | ✅ |
| 导出文件 | ✅ | ✅ | ✅ |
| 卷内搜索 | ✅ | ✅ | ✅ |
| 格式化 / 模板还原 / 映射盘符 | ✅ | ❌ | ❌ |
| FileVault 解锁 | ✅ | 仅标“加密”标签 | 仅标“加密”标签 |

跨平台版是**只读**的：不写盘、不改分区表。

## 6. 出问题怎么查

- Windows 日志：`%LOCALAPPDATA%\ApfsLens\log.txt`
- 跨平台日志：`~/.u-apfs/log.txt`
- 扫描失败时 Windows 版会在下载目录写一份 `apfslens-diag.txt`，记录偏移、块大小、失败原因；
- 「一键诊断」生成的报告可直接发我，里面有分区表、块大小、卷列表与各引擎的可用状态。

常见情况：

- **盘插上去但列表里没有**：多半是没给管理员权限（macOS 是「完全磁盘访问」没开）；
- **能进卷但目录是空的**：先确认是不是快照视图（右上角切回「当前」），再看日志里的块大小是否识别成 4096/8192/16384；
- **文件导出 0 字节**：该文件可能是 APFS 压缩文件（`UF_COMPRESSED`）或加密卷内文件，日志里会写明原因。
