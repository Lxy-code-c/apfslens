盘镜 APFS · ApfsLens 1.0.0（Windows 图形版）
====================================================

一句话：插上 Mac 用过的盘（APFS 格式），双击就能进去翻文件、导出文件。
不需要装任何东西，也不会弹命令行窗口。

怎么打开
  - 双击 launch.cmd（它会自动按你的 CPU 选 x64 / x86 / ARM64，并请求管理员权限）；
  - 或者直接双击对应架构的 apfslens-x64.exe / apfslens-x86.exe / apfslens-arm64.exe。
  读整块物理盘需要管理员权限，程序会自己申请；只读磁盘镜像（.dmg / .img）不需要。

界面里怎么用
  1. 左边选一块盘 → 看分区表与 APFS 容器的卷；
  2. 选卷 → 进目录；
  3. 选中文件点「导出」→ 存到「下载」目录。
  搜索框在卷内搜文件名；快照下拉可以切到某个快照的时间点看历史内容。

能做什么（Windows 版）
  - 只读浏览 APFS：卷、目录、文件、快照；
  - 格式化（NTFS / exFAT / FAT32 等），按分区或整盘；
  - APFS 模板还原：把 macOS 生成的空白 APFS 镜像写回分区；
  - 盘符映射「挂载到此电脑」：不装驱动也能在资源管理器里看到内容（只读）；
  - 加密（FileVault）卷解锁后浏览；
  - 一键诊断：本机生成一份报告，方便排查读不到盘的问题。

名字与版本
  中文名：盘镜 APFS
  英文名：ApfsLens
  版本：1.0.0（语义化版本，不再用日期当版本号）

附件说明（同目录）
  apfslens_native.exe / -x86.exe   大文件快速导出的原生引擎（可选，缺了会自动退回内置路径）
  apfslens_probe.exe / -x86.exe    分区表交叉核对引擎（可选）
  apfslens_doctor.py               诊断报告的排版脚本（可选，没有 Python 时用内置排版）

注意
  - 隐藏项（. 开头，如 .DS_Store、._xxx）在任何列表、搜索结果、下载里都不会出现；
  - 程序不写原盘（除你主动格式化 / 还原模板时）；
  - 日志在 %LOCALAPPDATA%\ApfsLens\log.txt，遇到问题把它发我。
